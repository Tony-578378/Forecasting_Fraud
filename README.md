# Introduction to the project

The project is aimed to investigate the relationships between macroeconomic indicators and the fraud level in the UK, and try to use these relationships to build models to forecast the fraud level in the UK. If you want to run the codes, please download the **Rmd** file and the **CSV** files, open them in **RStudio**, and following the comments. All important images and tables produced in this project are saved in the two folders as screenshots.

The 4 **CSV** files are the data used in this project. Data for the four macroeconomic indicators, CPIH, unemployment, index of production and industry sectors, and the Composite Consumer Confidence index, are collected from either the **Federal Reserve Bank of St. Louis** or the **Office for National Statistics**, and are for the UK. The fraud data are collected using the Guardian API, following specific criteria, to approximate the fraud level in the UK. However, for reproducibility of the results, when you run the codes, you may ignore the API fetching steps and start from line *130* (shown in **RStudio**), to directly use the data collected before. All data are monthly, and are ranged from 1999 to 2025. The 1999 to 2024 data are used as the training data, while the 2025 data are used as the test data.

Three types of forecasting models were used, which were GAM and XGBoost ones combined with time series models, and a VAR one. The VAR model stood out from the three, and was able to forecast the general trend of the fraud level (see *tables 11-12*). However, it failed to capture the large spikes in fraud, making the model immature to be used in industry.
